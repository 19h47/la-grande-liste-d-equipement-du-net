    L'API

    Une API en lecture seule, faite de simples fichiers JSON : pas de serveur ni de clé, et le CORS est ouvert par GitHub Pages. Toutes les chaînes existent en fr et en en.

    Point d'accèsContenu
    api/v1/index.jsonMétadonnées, crédits, unités, liste des points d'accès
    api/v1/items.jsonTous les objets
    api/v1/items/{id}.jsonUn objet, ex. epee-longue
    api/v1/categories.jsonLes 33 tableaux de la liste
    api/v1/categories/{id}.jsonUn tableau et ses objets, ex. taverne-et-auberge
    api/v1/currencies.jsonPièces et lingots (cuivre → Tellon)
    api/v1/search.jsonIndex léger pour la recherche

    Un objet

    {
 "id": "epee-longue",
 "category": "armes",
 "name": { "fr": "Épée longue", "en": "Long Sword" },
 "full_name": { "fr": "Épées — Épée longue", "en": "Sword — Long Sword" },
 "price": { "text": { "fr": "15 po", "en": "15gp" },
            "min_cp": 1500, "max_cp": 1500, "plus": false },
 "weight": { "text": "4", "lb": 4 },
 "notes": { "fr": [] },
 "source": { "table": "XXXII", "line": 3716 }
}

    Les prix sont convertis en pièces de cuivre (min_cp, max_cp) pour pouvoir trier et additionner : 1 po = 100 pc, 1 pe = 50 pc, 1 pa = 10 pc, 1 pp = 500 pc. Quand un prix n'est pas chiffrable (« Spécial », « Mort », « une rançon de roi »), min_cp vaut null, mais le texte est toujours là. Le poids est en livres ; « * » vaut 0,1 lb. Les œufs et petits de créatures ont eggs et young à la place de price, et les herbes price_raw et price_prepared.

    const r = await fetch("https://<utilisateur>.github.io/<depot>/api/v1/items/hydromel-au-miel-la-pinte.json");
const hydromel = await r.json();
console.log(hydromel.price.text.fr); // "5 pa"

    Les fichiers

    Le dépôt contient aussi data/items.json (la source de vérité), data/items.csv pour les tableurs, le texte original anglais, la traduction française complète (avec plus de 700 notes) et les notes de relecture. scripts/build.py régénère l'API à partir du JSON.
