    L'API

    Une API en lecture seule, faite de simples fichiers JSON : pas de serveur ni de clé. Toutes les chaînes existent en fr et en en.

    Point d'accèsContenu
    api/v1/index.jsonMétadonnées, crédits, unités
    api/v1/items.jsonTous les objets
    api/v1/items/{id}.jsonUn objet, ex. epee-longue
    api/v1/categories.jsonLes 33 tableaux
    api/v1/categories/{id}.jsonUn tableau et ses objets, ex. taverne-et-auberge
    api/v1/currencies.jsonPièces et lingots
    api/v1/search.jsonIndex léger pour la recherche

    {
 "id": "epee-longue",
 "category": "armes",
 "name": { "fr": "Épée longue", "en": "Long Sword" },
 "price": { "text": { "fr": "15 po", "en": "15gp" },
            "min_cp": 1500, "max_cp": 1500, "plus": false },
 "weight": { "text": "4", "lb": 4 },
 "notes": { "fr": [] },
 "source": { "table": "XXXII", "line": 3716 }
}

    Les prix sont en pièces de cuivre (min_cp, max_cp) : 1 po = 100 pc, 1 pe = 50 pc, 1 pa = 10 pc, 1 pp = 500 pc. Un prix non chiffrable (« Spécial », « Mort ») a min_cp: null, mais son texte reste fourni. Les poids sont en livres ; « * » vaut 0,1 lb.

    Données brutes, CSV, textes FR/EN et notes de relecture : le dépôt GitHub.
